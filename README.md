# Liberages

Rede Social e Mapa Interativo focado no público liberal.

This project is a rewrite and adaptation of the original Go-based Liberages backend into a modern TypeScript stack, utilizing **Bun**, **Hono**, **Drizzle**, and **SQLite**.

## Technical Specs

- See [SPEC.md](SPEC.md) for the product and architectural master specification.
- See [.stack.txt](.stack.txt) and [AGENTS.md](AGENTS.md) for the tech stack constraints.

## Architecture

The project follows a Modular Monolith architecture, incorporating Domain-Driven Design (DDD) principles and Clean Architecture (Adapters, Repositories, Interfaces).
